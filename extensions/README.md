# Расширения: драйверы других СУБД

sshdeck умеет PostgreSQL, MySQL/MariaDB и SQLite сам. Любую другую СУБД
можно подключить расширением — отдельной программой на любом языке.
Регистрировать ничего не нужно: sshdeck находит расширения сам при каждом
открытии диалога «Новое подключение к базе».

## Установка

Положите исполняемый файл в одно из мест:

- `~/.local/share/sshdeck/drivers/` — для себя;
- `/usr/share/sshdeck/drivers/` или `/usr/lib/sshdeck/drivers/` — для всех
  (так его может ставить пакет);
- куда угодно в `$PATH` под именем `sshdeck-driver-<имя>`.

Вместо файла можно положить каталог, в котором лежит исполняемый `driver`
(удобно, если расширению нужны свои файлы).

Пример из этого каталога (ClickHouse, нужен только Python 3):

```sh
install -Dm755 extensions/clickhouse/sshdeck-driver-clickhouse \
    ~/.local/share/sshdeck/drivers/clickhouse
```

После этого в диалоге подключения в списке «СУБД» появится
«ClickHouse (расширение)». Кнопка с папкой под списком открывает каталог
расширений.

## Протокол

### Описание

`<программа> --sshdeck-info` печатает одну строку JSON и завершается:

```json
{"sshdeck_driver": 1, "id": "clickhouse", "name": "ClickHouse",
 "badge": "CH", "default_port": 8123, "default_user": "default", "file": false}
```

| Поле             | Смысл                                                         |
|------------------|---------------------------------------------------------------|
| `sshdeck_driver` | версия протокола, сейчас `1`                                  |
| `id`             | идентификатор (латиница, цифры, `-`, `_`); пишется в профиль  |
| `name`           | название СУБД в интерфейсе                                    |
| `badge`          | 2–3 буквы для значка (по умолчанию — первые буквы `id`)       |
| `default_port`   | порт по умолчанию                                             |
| `default_user`   | пользователь по умолчанию                                     |
| `file`           | `true` — база это файл (как SQLite): вместо сервера путь      |

### Сеанс

Для подключения программа запускается без аргументов. Дальше — строки JSON:
запрос в stdin, ответ в stdout, по одной строке на сообщение.

```
→ {"id": 1, "method": "connect", "params": {...}}
← {"id": 1, "result": {...}}
← {"id": 2, "error": "текст ошибки"}
```

- Ответ должен содержать `id` запроса. Запросы могут приходить, не
  дожидаясь ответа на предыдущий: отвечайте по порядку или по `id`.
- Сообщение `{"method": "cancel"}` (без `id`) просит прервать текущий
  запрос; ответа на него не нужно. Если расширение так не умеет, его можно
  игнорировать — sshdeck через 3 секунды перестанет ждать ответа.
- stderr показывается пользователю, если программа завершится.
- Когда вкладку закрывают, stdin закрывается и процесс завершается.

Значения в строках результатов — строки, числа, `true`/`false` или `null`.

| Метод       | `params`                                                      | `result`                                                          |
|-------------|---------------------------------------------------------------|-------------------------------------------------------------------|
| `connect`   | `host`, `port`, `user`, `password`, `database`, `path`, `tls` | `{"version": "ClickHouse 25.8"}`                                  |
| `query`     | `sql`, `limit` (число или `null` — все строки, для экспорта)  | `columns`, `rows`, `truncated`, `affected`, `statements`, `types` |
| `tables`    | —                                                             | `{"schemas": [...], "tables": [{"schema", "name", "view", "size", "rows"}]}` |
| `structure` | `schema`, `table`                                             | `{"columns": [{"name", "type", "nullable", "default", "key"}]}`   |
| `insert`    | `schema`, `table`, `columns`, `rows`, `truncate`              | `{"affected": N}`                                                 |

Подробности:

- `query`: `columns` — имена колонок (пусто, если запрос не вернул строк),
  `rows` — массив массивов, `truncated` — строк было больше `limit`,
  `affected` — сколько строк изменил запрос без результата, `statements` —
  сколько запросов выполнено, `types` (необязательно) — `"number"`, `"bool"`
  или `"text"` для каждой колонки: по ним экспорт в JSON и SQL пишет числа
  без кавычек.
- `tables`: `size` — размер в байтах, `rows` — примерное число строк; оба
  необязательны. Таблицы показываются в дереве с размерами.
- `insert`: импорт из CSV/JSON. Строки приходят порциями по 1000; в первой
  порции `truncate: true` означает «сначала удалить строки таблицы».
- Если подключение идёт через SSH, sshdeck сам поднимает туннель и передаёт
  в `connect` адрес `127.0.0.1` и локальный порт.
